2The plan in brief

Onboarding clients means checking their documents against control lists, and doing it by hand is slow and uneven. The agent builds the file for each synthetic application for the compliance officer: it extracts the data, checks the lists, investigates doubtful matches, and calculates a rule-based risk score. It never approves a high-risk client without a person, never rejects without a person, and never follows instructions written inside the documents.

The flow, in 9 steps (all 9 ran)

  1. 1
    The request arrives with its identity documents, economic activity, and source-of-funds documents.
    done
  2. 2
    The input guard looks for hidden instructions in the documents.
    done
  3. 3
    The extractor pulls the data out of the documents.
    done
  4. 4
    The verifier checks the name against the control lists, both exactly and approximately.
    done
  5. 5
    If the resemblance falls in the grey zone, the context investigator checks whether it is the same person or a namesake.
    done
  6. 6
    The risk score is calculated with rules.
    done
  7. 7
    A decision is made: approve, reject, or escalate to the officer. Every rejection and every doubtful case goes through the officer.
    done
  8. 8
    The file is written, citing the rule or match behind each conclusion.
    done
  9. 9
    The output guard reviews the file.
    done

One-way decisions: they cannot be undone

  • D1 · Which matches require a person without exception?Binding lists require blocking and escalation (Law 1121 art. 20; AMLR 76(5)).

The other 3 decisions are two-way: they can be reversed if the measurement calls for it.

6Assumptions

Assumptions are what the plan took as true without having tested it. Each comes with a cheap test; the verifier runs it and says whether it was confirmed, refuted or left untested.

S2

The multi-agent (extractor and context investigator) does no worse than a single agent at no larger budget.

Refutedmedium criticality

The plan assumed that the extractor and the investigator, kept apart, would do no worse than a single agent. They got the same right (100% against 100%) but took a little longer (6.0 s against 5.9 s), and the plan only tolerates the same delay: refuted.
