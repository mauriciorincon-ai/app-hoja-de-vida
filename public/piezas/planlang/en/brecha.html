A verifier with no language model compares, case by case, what the plan promised with what the agent did, and publishes the result with its failures in view.

2The plan in brief

A synthetic insurer receives prior-authorization requests with the physician's free text, an attached order and member data. The agent must approve (in full or up to the service's cap), deny with an enumerated cause, or escalate to a human auditor — never fully denying on its own, never leaking member data, never obeying instructions hidden in the text. Simulated volume: 200 cases per full batch.

The flow, in 9 steps (all 9 ran)

  1. 1
    The request arrives; the router classifies the type of care.
    done
  2. 2
    The input guard looks for hidden instructions in the request; if it finds any, the decision goes to a person.
    done
  3. 3
    If it is an emergency or an exempt service, it is approved without a coverage check (law and benefit plan).
    done
  4. 4
    The extractor turns the text into fields with a stated confidence.
    done
  5. 5
    If required fields are missing, a clarification is requested (max 2 cycles).
    done
  6. 6
    If the model does not respond while extracting or clarifying, the case goes to a person with whatever there is; it is never made up.
    done
  7. 7
    The coverage checker applies rules: exempt services, exclusions with a ground, high cost, the service's coverage cap and order/text contradiction.
    done
  8. 8
    Decision: approve, approve up to the service's cap (with Texas mode, with a human), deny (always with a human) or escalate to the auditor.
    done
  9. 9
    The writer drafts the response; the deterministic guard filters it; if adverse, the adverse-decision document is issued.
    done

One-way decisions: they cannot be undone

  • D1 · Which member data reach the model?Legal data minimization (Law 1581 arts. 3–6, GDPR art. 9) and a trivial output guard.
  • D2 · Which decisions may the agent take without a human?CA SB 1120, TX SB 815, AI Act art. 14; the app's hard rule. Approving in part (up to the service's cap, RB-08) is a partial adverse determination: Texas forbids it automated, so Texas mode sends it to a person; without it, it goes out on its own. A full denial always goes to a person.

The other 4 decisions are two-way: they can be reversed if the measurement calls for it.
