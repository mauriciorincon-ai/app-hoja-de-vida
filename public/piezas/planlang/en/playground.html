Demo A · run suscripcion-planlang-a-002-200-v1.5 · 200 cases · 624 recorded decisions

What if the plan had set other thresholds?

Move the plan’s thresholds and see which cases would have taken another path, which errors appear or are avoided and how much human work it costs. Everything is recomputed over the decisions the agent already took: nobody calls the model again.

This run’s human decisions were simulated. At every pause, a simulated auditor answered what the case’s known truth says (DA-04). Cases, members and the benefits plan are synthetic.

The playground at a glance

Read as

Reading as leader. You see what changes and what it costs, in plain words, with an example.

Reading as expert. You get the technical record, the decision rule with the values you move, what was observed at each threshold, the rule applied to each change and the signals of the decisions.

Goal

Try other values for the plan’s thresholds over what the agent already did, and see the cost of each change before touching the plan.

200 cases · 624 decisions

An example. If you raise the minimum extraction confidence (U1) from 0.75 to 0.85, cases A-089 and A-144 —which the agent resolved alone, each with confidence 0.80— would go to a person: 24 more auditor minutes and no new error. Try it below.

What the playground cannot know

  • Moving a threshold recomputes, on the recorded signals, which branch each deciding node would have taken. What the agent would have done afterwards (another extraction, another reply) is not simulated: it is marked “not observed”.
  • U4 (Texas mode): switching it changes 9 of the 624 decisions recorded in this run.
  • The texas_y_no_aprobar(modo_texas, propuesta) rule can be recomputed: its inputs are in every trace.

The calculation is done by planlang’s core in your browser. It is the same edge interpreter that matches Python on the 1124 decisions of the runs (RF-09.2), and it calls no model.
