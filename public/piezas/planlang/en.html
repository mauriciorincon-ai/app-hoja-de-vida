How each claim holds up

AI-free core
planner, verifier and playground call no model and read no clock or randomness (canonical JSON RFC 8785 + SHA-256); the playground, which runs in your browser, gives the same bytes in Node, Chromium, Firefox and WebKit
Own traces
planlang-trace/v1, each with its fingerprint; LangSmith is only an observability mirror
Cross-check
RF-09.2: the graph (Python) and the playground (TypeScript) evaluate the same plan rule; 0 differences in 1124 decisions across 2 runs
Model
sonnet through the author’s Claude Code subscription, in batches of 20 outside CI, with a switch to a keyed API
Human decisions
simulated in batch: the reviewer —the auditor in A, the officer in B— follows each case’s known truth (DA-04), and the showcase says so on every screen
Stack
LangGraph 1.2.12 · LangChain 1.4.2 · Python 3.12 · Claude Code 2.1.282 · Next.js static export · strict TypeScript

The 2026 interview question

How do you know your evaluation is trustworthy?

With a deterministic verifier over cases with known truth and seeded adversaries: no language model decides whether the agent got it right. And with the gap published even when it is unfavorable.

Simulation · not operational. Every case, member, physician, benefit plan, applicant and watchlist is synthetic. Both demos' human decisions were simulated in batch following the known truth; in production a person would make them with the full case: a medical auditor in A, a compliance officer in B.
